# SportSync: one-page project summary

**Smarter Scheduling. Stronger Teams.** · Independent product design & development portfolio project by Maria Zha-Zha C. Bio. Not affiliated with any company. All data fictional.

## Problem
Youth and community sports run on volunteers. Schedules live in spreadsheets and group chats; one change (weather, venue maintenance, a coach's shift) cascades into double-bookings, missed games and hours of messaging.

## Who it's for
League administrators · organization managers · volunteer coaches · parents · athletes · facility managers (six roles with permissions).

## What I designed and built
| Area | Highlights |
|---|---|
| Scheduling | Day-by-venue, week, month and list views; create/edit/duplicate/cancel/postpone/restore; weekly recurrence with this / following / all edits |
| Conflicts | 10 types detected live (venue, team, coach, player, rest, closure, hours, maintenance, capacity, recurring); 3 ranked alternatives with reasons; confirm with before → after |
| AI assistant (simulated) | Plain-language request → "What I understood" → proposal with "Why this schedule", fairness stats, editable rows → approve / reject / revise → undo |
| People | RSVP per child for parents; expected attendance and reminders for coaches; attendance tracking |
| Reach | Real .ics export; Google/Outlook add-event links; simulated OAuth sync; CSV import with validation; share links; notification history, previews and preferences |
| Quality | Loading, empty, error, offline and permission states; WCAG 2.2 AA targets; unit + Playwright tests |
